# پروژه سنگ، کاغذ، قیچی با دوربین لپتاپ و یادگیری خودکار

این پروژه با پایتون ساخته شده و کارهای زیر را انجام می‌دهد:

- گرفتن تصویر از دوربین لپتاپ
- تشخیص دست با MediaPipe
- جمع‌آوری نمونه از دست خودتان برای:
  - سنگ / مشت
  - کاغذ
  - قیچی
- آموزش مدل Machine Learning روی نمونه‌های خودتان
- ذخیره دیتاست و مدل روی سیستم
- اجرای بازی با شمارش معکوس
- انتخاب تصادفی سیستم در ثانیه 3
- تشخیص حرکت شما و اعلام برنده
- اصلاح مدل وقتی confidence پایین است

---

## 1. نصب پیش‌نیازها

داخل پوشه پروژه، این دستور را بزنید:

```bash
pip install -r requirements.txt
```

اگر چند نسخه پایتون دارید، ممکن است لازم باشد این را بزنید:

```bash
python -m pip install -r requirements.txt
```

---

## 2. اجرای برنامه

```bash
python main.py
```

---

## 3. روش آموزش مدل

وقتی پنجره دوربین باز شد:

| کلید | کاربرد |
|---|---|
| `r` | ذخیره حالت فعلی دست به عنوان سنگ / مشت |
| `p` | ذخیره حالت فعلی دست به عنوان کاغذ |
| `s` | ذخیره حالت فعلی دست به عنوان قیچی |
| `t` | آموزش مدل |
| `g` | شروع بازی |
| `h` | نمایش راهنما در ترمینال |
| `q` | خروج |

برای شروع، حداقل برای هر کلاس 15 نمونه بگیرید:

- 15 نمونه سنگ / مشت
- 15 نمونه کاغذ
- 15 نمونه قیچی

ولی برای دقت بهتر، پیشنهاد می‌شود برای هرکدام 50 تا 100 نمونه بگیرید.

نمونه‌ها را با زاویه‌ها و فاصله‌های متفاوت بگیرید تا مدل فقط یک حالت خاص را حفظ نکند.

---

## 4. فایل‌هایی که ساخته می‌شود

بعد از اجرای برنامه، پوشه `data` ساخته می‌شود:

```text
data/
├── rps_dataset.csv
└── rps_model.joblib
```

- `rps_dataset.csv`: دیتاست حرکات دست شما
- `rps_model.joblib`: مدل آموزش‌دیده

اگر خواستید از صفر شروع کنید، پوشه `data` را پاک کنید.

- قیچی، کاغذ را می‌برد
- کاغذ، سنگ را می‌برد

## 6. نکته مهم درباره فارسی در پنجره OpenCV

OpenCV متن فارسی را روی تصویر درست نمایش نمی‌دهد.  
برای همین پیام‌های اصلی فارسی در ترمینال چاپ می‌شوند و روی تصویر متن انگلیسی کوتاه نمایش داده می‌شود.

---

## 7. اگر دوربین باز نشد

این موارد را بررسی کنید:

1. برنامه دیگری مثل Zoom، OBS یا مرورگر از دوربین استفاده نکند.
2. دسترسی Camera برای Python فعال باشد.
3. اگر چند دوربین دارید، در `main.py` این خط را تغییر دهید:

```python
cap = cv2.VideoCapture(0)
```

مثلا:

```python
cap = cv2.VideoCapture(1)
```
